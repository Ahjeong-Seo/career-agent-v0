# ADR 0002: 재작성 의견을 다음 루프에 전달

## 결정

- 첫 생성의 세 스타일 결과는 하나의 `rewrite.json`으로 받고, 스타일 선택 화면이 결과를 스타일별로 나눈다.
- 사용자는 화면 순번이 아니라 기존 `style_id`를 기준으로 다음 재작성을 요청한다. `rewrite.json` 스키마에 새 스타일 필드를 추가하지 않는다.
- 미통과 score의 `feedback`은 다음 재작성 전에 편집할 수 있다. 원래 점수 결과는 보존하고, 편집 내용은 해당 스타일·attempt의 화면 상태로 유지한다.
- 재작성에 실제 전달한 score feedback은 생성된 attempt의 현재 세션 이력에 기록하고, 사용자가 해당 attempt 아래에서 확인할 수 있게 한다.
- 사용자는 각 rewrite 문장에도 항목별 `user_feedback`을 입력한다. score feedback과 항목별 의견을 모두 다음 루프 입력으로 전달한다.
- 통과 결과는 수정 없이 최종 결과로 이동한다.
- 최종 TXT는 실제 문장이 있는 항목만 `item_id. 항목명 : 문장` 형식으로 내보낸다.

## 근거

`rewrite.json`에는 이미 스타일 ID와 항목별 `user_feedback`이 있으며, 채점 결과에는 미통과 시 안내용 `feedback`이 있다. 이를 별도 스키마 필드로 중복 정의하지 않고 사용한다.
